# Final Project CDS303 FALL2026
## Anza Amatya and Yina Yoon

### Project Overview

This project examines patterns of crime reported in Washington DC across locations and time and how those patterns relate to economic characteristics of the neighborhoods in which the crime incidents occur. The main dataset used for this project is Crime Incidents in 2025 from Open Data DC, which records the time and place of each incident reported and its type of offense and method. Incidents will be grouped into clusters according to their location and time, then a classification model will be built based on their offense type and method. A supplementary dataset by American Community Survey will be explored to link economic traits of neighborhoods in DC to the patterns observed from the crime dataset to understand if similar economic conditions associates with similar crime patterns.

### Initial Research Question:

How do spatial and temporal patterns of crime in Washington DC relate to the economic characteristics of the regions where the incidents occur?
